# Feature: ตรวจสอบสถานะอุปกรณ์ (Equipment Status)
Spec ID: SPEC-EQS-001 | Source: US-001, RQ-02, RQ-05, RQ-09, Journey Map เฟส "ตรวจสอบอุปกรณ์ที่ต้องการยืม" | Use case: UC-01

Backlog: BL-01, BL-02, BL-03, BL-04 (specs/backlog.md)

## Goal
นักศึกษาที่ยืนยันตัวตนแล้ว ค้นหาและตรวจสอบสถานะอุปกรณ์ของภาควิชาได้ด้วยตนเองภายใน 1 นาที
โดยไม่ต้องเดินไปสอบถามเจ้าหน้าที่ (เดิมใช้เวลา 5-10 นาที) และเจ้าหน้าที่ลดภาระการตอบคำถามซ้ำ

## Scope
### In scope
- แสดงรายการอุปกรณ์แบบจัดกลุ่มตามรุ่น/ชนิด พร้อมจำนวนที่ว่าง/ทั้งหมด และสถานะล่าสุดรายชิ้น
- ค้นหาด้วยชื่อ/รหัสอุปกรณ์ และกรองตามประเภทและสถานะ
- แสดงรายละเอียดอุปกรณ์รายชิ้น รวมกำหนดคืนหรือป้าย "เลยกำหนดคืน" กรณีถูกยืมอยู่ (CR-001, CR-002)
- แสดงข้อมูลตามสิทธิ์ของผู้ใช้ (นักศึกษา / เจ้าหน้าที่) (CR-002)
### Out of scope
- ส่งคำขอยืม (UC-02) | บันทึกการส่งมอบ (UC-08) | บันทึกการรับคืน (UC-09) | จัดการรายการอุปกรณ์ (UC-10)
- ยืนยันตัวตน (ระบบยืนยันตัวตนของมหาวิทยาลัย IF-IDP-01) - ถือว่าทำสำเร็จแล้วก่อนเข้าฟีเจอร์นี้ (precondition)
- จองอุปกรณ์ล่วงหน้า (BL-11) - Won't เทอมนี้ ตามข้อตกลง N-01 (ปิด Q-02)

## Constraints
ใช้ร่วม (ข้อความเต็มอยู่ที่ specs/000-shared/constraints.md ห้าม copy มาไว้ที่นี่):
- CON-TECH-01 ฐานข้อมูล PostgreSQL
- CON-TECH-02 HTTPS เท่านั้น deploy ด้วย Docker
- CON-DATA-01 สถานะอุปกรณ์ 3 ค่าเท่านั้น: ว่าง, ถูกยืม, ไม่พร้อมใช้งาน
- CON-DATA-03 รหัสครุภัณฑ์ไม่ซ้ำกัน
- DOM-PRIV-01 นักศึกษาไม่เห็นชื่อผู้ยืมรายอื่น
- DOM-AUDIT-01 audit log ทุกครั้งที่เข้าถึงข้อมูลอุปกรณ์
- DOM-ACCESS-01 นักศึกษาเห็นเฉพาะอุปกรณ์ภาควิชาของตนเอง
- DOM-LOAN-01 ยืมแบบปกติคืนภายใน 16:00 น. วันเดียวกัน
- IF-IDP-01 ต้องยืนยันตัวตนผ่านระบบยืนยันตัวตนของมหาวิทยาลัยก่อน และได้ภาควิชาของผู้ใช้กลับมา
เฉพาะฟีเจอร์นี้:
- CON-DATA-02 ฟีเจอร์นี้เป็น read-only ไม่มีการเปลี่ยนสถานะอุปกรณ์จากที่นี่
  สถานะถูกเปลี่ยนโดย UC-08 (ส่งมอบ), UC-09 (รับคืน), UC-07 (ตรวจสอบอุปกรณ์ที่คืน), UC-10 (จัดการรายการอุปกรณ์)
  ดูตาราง "ใครเปลี่ยนสถานะอุปกรณ์" ใน specs/000-shared/data-model.md

## Requirements
- FR-EQS-01 ระบบต้องแสดงรายการอุปกรณ์แบบแบ่งหน้า โดย 1 แถวคือ 1 รุ่น/ชนิด
  แสดงชื่อรุ่น ประเภท และจำนวนที่ว่าง/จำนวนทั้งหมด
  เมื่อเลือกแถวแล้วแสดงอุปกรณ์รายชิ้นตามรหัสครุภัณฑ์ (CON-DATA-03)
  พร้อมสถานะล่าสุดของแต่ละชิ้น                                        <- UC-01 main flow ขั้น 3-4, RQ-02
- FR-EQS-02 ระบบต้องค้นหาอุปกรณ์จากชื่อหรือรหัสอุปกรณ์
  และกรองตามประเภทและสถานะได้                                       <- UC-01 main flow ขั้น 5-6, RQ-05
- FR-EQS-03 เมื่อค้นหาแล้วไม่พบข้อมูล ระบบต้องแจ้งว่าไม่พบอุปกรณ์
  พร้อมเสนอทางเลือกล้างตัวกรอง                                        <- UC-01 alternative 6a
- FR-EQS-04 เมื่ออุปกรณ์มีสถานะ "ถูกยืม" ระบบต้องไม่แสดงปุ่มส่งคำขอยืม และ
  (ก) ถ้ายังไม่เลยกำหนดคืน ต้องแสดงกำหนดคืน (วันที่และเวลา)
  (ข) ถ้าเลยกำหนดคืนแล้ว (วันที่และเวลาปัจจุบันตาม Asia/Bangkok > กำหนดคืน) ต้องแสดงป้าย "เลยกำหนดคืน"
      แทนกำหนดคืนสำหรับนักศึกษา ส่วนเจ้าหน้าที่เห็นทั้งกำหนดคืนและป้าย
  กำหนดคืนของการยืมแบบปกติคือ 16:00 น. ของวันที่ยืม (DOM-LOAN-01)
  ป้าย "เลยกำหนดคืน" ไม่ใช่สถานะใหม่ สถานะยังเป็น "ถูกยืม" (CON-DATA-01)   <- UC-01 alternative 8a, CR-001, CR-002
- FR-EQS-05 เมื่ออุปกรณ์มีสถานะ "ไม่พร้อมใช้งาน" ระบบต้องแสดงป้าย "ไม่พร้อมใช้งาน"
  และไม่อนุญาตให้ส่งคำขอยืม                                           <- UC-01 alternative 8b, RQ-09, CR-002
- FR-EQS-06 เมื่ออุปกรณ์มีสถานะ "ว่าง" ระบบต้องเปิดให้ส่งคำขอยืมต่อได้
  โดยส่งข้อมูลอุปกรณ์ที่เลือกไปยัง UC-02                                <- UC-01 alternative 8c
- FR-EQS-07 ระบบต้องแสดงข้อมูลตามสิทธิ์: เจ้าหน้าที่เห็นชื่อผู้ยืมปัจจุบัน
  และสรุปจำนวนอุปกรณ์แยกตามสถานะ นักศึกษาไม่เห็น                       <- UC-01 alternative 3a
- FR-EQS-08 เมื่อดึงข้อมูลจากฐานข้อมูลไม่สำเร็จ ระบบต้องแจ้งข้อผิดพลาด
  พร้อมเปิดให้ลองใหม่ และต้องไม่แสดงข้อมูลเก่าที่อาจไม่ถูกต้อง               <- UC-01 exception E2
- FR-EQS-09 [ยกเลิกโดย CR-002 2569-11-02] (เดิม: สถานะ "รออนุมัติ") ไม่มีสถานะนี้ใน CON-DATA-01 แล้ว ห้ามนำ ID นี้กลับมาใช้
- FR-EQS-10 ระบบต้องอนุญาตให้นักศึกษาเข้าดูรายการอุปกรณ์เฉพาะภาควิชาของตนเอง (DOM-ACCESS-01)
  นักศึกษาภาควิชาอื่นต้องได้รับข้อความแจ้งว่าไม่มีสิทธิ์เข้าถึง และไม่ได้รับข้อมูลอุปกรณ์

## Quality Requirements
- NFR-PERF-01 การค้นหาและแสดงรายการอุปกรณ์: เวลาตอบสนอง p95 <= 3 วินาที
  ที่ข้อมูลอุปกรณ์ 1,000 รายการ และผู้ใช้พร้อมกัน 50 คน (RQ-24, CR-002)
- NFR-DATA-01 สถานะที่แสดงต้องคลาดเคลื่อนจากฐานข้อมูลจริงไม่เกิน 30 วินาที (ตีความ "เรียลไทม์" ของ RQ-02)
- NFR-SEC-01 ข้อมูลเข้ารหัสขณะรับส่งด้วย TLS 1.2 ขึ้นไป และต้องผ่านการยืนยันตัวตนก่อนทุกครั้ง
- NFR-AVAIL-01 ระบบพร้อมใช้งานอย่างน้อย 99% ในช่วง 08.30-16.30 น. วันจันทร์-ศุกร์
- NFR-USE-01 ใช้งานได้บนหน้าจอมือถือ และผู้ใช้ใหม่ค้นหาสถานะอุปกรณ์ที่ต้องการได้
  ภายใน 1 นาที โดยผู้ทดสอบ 8 ใน 10 คนทำสำเร็จโดยไม่ต้องขอความช่วยเหลือ

## Acceptance Criteria
- [ ] AC-EQS-01 (FR-EQS-01)
      Given นักศึกษายืนยันตัวตนแล้ว และมีอุปกรณ์รุ่นหนึ่ง 5 ชิ้น ว่าง 3 ชิ้น
      When  เปิดหน้ารายการอุปกรณ์ แล้วเลือกรุ่นนั้น
      Then  รายการแสดงรุ่นนั้น 1 แถว ระบุประเภทและ "ว่าง 3 / ทั้งหมด 5"
            และเมื่อเลือกแล้วเห็นอุปกรณ์ 5 ชิ้นตามรหัสครุภัณฑ์พร้อมสถานะของแต่ละชิ้น
- [ ] AC-EQS-02 (FR-EQS-02)
      Given อยู่ในหน้ารายการอุปกรณ์
      When  ค้นหาด้วยคำว่า "Notebook" และกรองสถานะ "ว่าง"
      Then  แสดงเฉพาะอุปกรณ์ที่ชื่อหรือรหัสตรงกับคำค้น และมีสถานะว่างเท่านั้น
- [ ] AC-EQS-03 (FR-EQS-03)
      Given ค้นหาด้วยคำที่ไม่มีในระบบ
      When  กดค้นหา
      Then  แจ้งว่าไม่พบอุปกรณ์ และมีทางเลือกล้างตัวกรองกลับไปดูรายการทั้งหมด
- [ ] AC-EQS-04 (FR-EQS-04, CON-DATA-02)
      Given เจ้าหน้าที่บันทึกการส่งมอบอุปกรณ์ชิ้นหนึ่งใน UC-08 แล้ว และยังไม่เลยกำหนดคืน
      When  นักศึกษาเปิดดูอุปกรณ์ชิ้นนั้น
      Then  สถานะแสดงเป็น "ถูกยืม" พร้อมกำหนดคืน (วันที่และเวลา) และไม่มีปุ่มส่งคำขอยืม
- [ ] AC-EQS-05 (FR-EQS-06, NFR-DATA-01)
      Given เจ้าหน้าที่บันทึกการรับคืนใน UC-09 สภาพปกติ
      When  นักศึกษารีเฟรชหน้ารายการภายใน 30 วินาที
      Then  สถานะเปลี่ยนเป็น "ว่าง" และปุ่มส่งคำขอยืมกลับมาใช้งานได้
- [ ] AC-EQS-06 (FR-EQS-05)
      Given อุปกรณ์มีสถานะ "ไม่พร้อมใช้งาน"
      When  นักศึกษาเปิดดูรายละเอียด
      Then  แสดงป้าย "ไม่พร้อมใช้งาน" และไม่มีปุ่มส่งคำขอยืม
- [ ] AC-EQS-07 (FR-EQS-07, DOM-PRIV-01)
      Given อุปกรณ์กำลังถูกยืมโดยนักศึกษาคนอื่น
      When  นักศึกษาทั่วไปเปิดดูรายละเอียด และเจ้าหน้าที่เปิดดูรายละเอียดเดียวกัน
      Then  นักศึกษาไม่เห็นชื่อผู้ยืม แต่เจ้าหน้าที่เห็นชื่อผู้ยืมปัจจุบัน
- [ ] AC-EQS-08 (FR-EQS-08)
      Given ฐานข้อมูลไม่ตอบสนอง
      When  เปิดหน้ารายการอุปกรณ์
      Then  แสดงข้อความผิดพลาดพร้อมปุ่มลองใหม่ ไม่แสดงหน้าจอค้างและไม่แสดงข้อมูลเก่า
- [ ] AC-EQS-09 (IF-IDP-01)
      Given session หมดอายุ
      When  เรียกดูรายการอุปกรณ์
      Then  ส่งกลับหน้าเข้าสู่ระบบพร้อมข้อความแจ้ง และกลับมาหน้าเดิมได้หลังล็อกอินสำเร็จ
- [ ] AC-EQS-10 (NFR-PERF-01)
      Given ข้อมูลอุปกรณ์ 1,000 รายการ และผู้ใช้พร้อมกัน 50 คน
      When  ค้นหาอุปกรณ์
      Then  p95 ของเวลาตอบสนอง <= 3 วินาที
- [ ] AC-EQS-11 (DOM-AUDIT-01)
      Given มีการเปิดดูรายละเอียดอุปกรณ์
      When  การเข้าถึงเสร็จสิ้น
      Then  มี audit log ที่ระบุผู้เข้าถึง เวลา และรหัสอุปกรณ์ที่เปิดดู
- [x] AC-EQS-12 [ยกเลิกโดย CR-002 2569-11-02] ตรวจ FR-EQS-09 ที่ถูกยกเลิก ห้ามนำ ID นี้กลับมาใช้
- [ ] AC-EQS-13 (FR-EQS-10, DOM-ACCESS-01)
      Given นักศึกษาภาควิชา A ยืนยันตัวตนแล้ว และอุปกรณ์เป็นของภาควิชา B
      When  เปิดหน้ารายการอุปกรณ์ หรือเรียกรายละเอียดอุปกรณ์ของภาควิชา B โดยตรง
      Then  แจ้งว่าไม่มีสิทธิ์เข้าถึง และไม่มีข้อมูลอุปกรณ์ของภาควิชา B ถูกส่งกลับ
- [ ] AC-EQS-14 (FR-EQS-04, DOM-PRIV-01, DOM-LOAN-01, CR-001, CR-002)
      Given อุปกรณ์ชิ้นหนึ่งสถานะ "ถูกยืม" แบบปกติ กำหนดคืน 2569-10-10 16:00 และเวลาปัจจุบันคือ 2569-10-10 17:00
      When  นักศึกษาเปิดดูรายละเอียด และเจ้าหน้าที่เปิดดูรายละเอียดเดียวกัน
      Then  นักศึกษาเห็นสถานะ "ถูกยืม" กับป้าย "เลยกำหนดคืน" ไม่เห็นกำหนดคืน 2569-10-10 16:00
            และไม่มีปุ่มส่งคำขอยืม ส่วนเจ้าหน้าที่เห็นทั้งกำหนดคืน 2569-10-10 16:00 และป้าย "เลยกำหนดคืน"

## Assumptions & Open Questions
- ASM-01 ข้อมูลอุปกรณ์ตั้งต้นถูกนำเข้าระบบโดยเจ้าหน้าที่ก่อนเปิดใช้งานจริง
- ASM-02 ระบบยืนยันตัวตนใช้บัญชีของมหาวิทยาลัยที่มีอยู่แล้ว ผ่าน Auth API (IF-IDP-01, RQ-23)
- ASM-03 ประเภทอุปกรณ์ (category) อ่านจากข้อมูลที่เจ้าหน้าที่กำหนดไว้แล้วใน UC-10
- Q-01 [ปิดแล้ว 2569-10-03] นักศึกษาเห็นกำหนดคืนตาม FR-EQS-04
  ยืนยันกับเจ้าหน้าที่ภาควิชาแล้ว เปลี่ยนการแสดงผลกรณีเลยกำหนดคืนตาม CR-001
- Q-02 [ปิดแล้ว 2569-10-02] ไม่ทำจองล่วงหน้าเทอมนี้ (Won't) แลกกับการแสดงกำหนดคืนตาม FR-EQS-04
  ตัดสินโดยอาจารย์หัวหน้าโครงการ ดูบันทึกการเจรจา N-01 ใน specs/backlog.md
- Q-03 [ปิดแล้ว 2569-09-20] เฉพาะนักศึกษาภาควิชานี้ ดู DOM-ACCESS-01, FR-EQS-10
- Q-04 ประเภทอุปกรณ์กำหนดตายตัว หรือให้เจ้าหน้าที่เพิ่มเองได้? -> ถามนักคอมพิวเตอร์
- Q-05 [ตรวจคำกำกวม 2569-11-02] FR-EQS-01 "แบ่งหน้า" หน้าละกี่รุ่น? (plan เสนอ 20 แต่ไม่มีที่มา) -> ถามนักศึกษา/เจ้าหน้าที่
