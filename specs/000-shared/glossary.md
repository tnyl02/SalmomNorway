# คำศัพท์ที่ใช้ร่วมกัน (glossary)
Status: v2 | Updated: 2569-11-02 (CR-002)

ทุก spec ต้องใช้คำเดียวกันสำหรับสิ่งเดียวกัน ถ้าเจอคำใหม่ให้เพิ่มที่นี่ก่อน

- อุปกรณ์รายชิ้น = อุปกรณ์ 1 ชิ้นที่มีรหัสครุภัณฑ์ของตัวเอง (ไม่ใช้คำว่า "เครื่อง" หรือ "ชิ้นงาน")
- รุ่น/ชนิด = กลุ่มของอุปกรณ์รายชิ้นที่เป็นรุ่นเดียวกัน 1 แถวในหน้ารายการ (FR-EQS-01)
- รหัสครุภัณฑ์ = รหัสประจำอุปกรณ์รายชิ้น ไม่ซ้ำกันทั้งระบบ (CON-DATA-03)
- สถานะ (ของอุปกรณ์) = 1 ใน 3 ค่าของ CON-DATA-01: ว่าง, ถูกยืม, ไม่พร้อมใช้งาน
  "พร้อมให้ยืม" (RQ-13, US-010) = ว่าง / "ชำรุด" "ส่งซ่อม" "สูญหาย" = เหตุที่ทำให้ไม่พร้อมใช้งาน ไม่ใช่สถานะ
- สถานะของคำขอ = สถานะของคำขอยืม แยกจากสถานะอุปกรณ์ (ดู data-model.md)
- ยืมแบบปกติ = ยืมแล้วคืนภายใน 16:00 น. วันเดียวกัน (DOM-LOAN-01)
- ยืมแบบค้างคืน = ยืมข้ามวัน ต้องมีเอกสารที่อาจารย์หัวหน้าโครงการเซ็นอนุมัติ (RQ-15, RQ-16)
- ป้าย "เลยกำหนดคืน" = ป้ายที่แสดงเพิ่มบนอุปกรณ์สถานะ "ถูกยืม" เมื่อเวลาปัจจุบันเกินกำหนดคืน **ไม่ใช่สถานะ** (CR-001, CR-002)
- กำหนดคืน = วันที่และเวลาที่ผู้ยืมต้องคืนอุปกรณ์ บันทึกตอนส่งมอบ (UC-08)
- คำขอยืม = คำขอที่นักศึกษาส่งสำหรับอุปกรณ์ ก่อนได้รับการอนุมัติ
- ผู้ยืม = ผู้ใช้ที่มีการยืม (Loan) ที่ยังไม่คืน
- นักศึกษา / เจ้าหน้าที่ = 2 บทบาทของผู้ใช้ระบบ (actor ใน Use Case Diagram) ไม่ใช้คำว่า "user" "แอดมิน" หรือ "ผู้ดูแล"
- เจ้าหน้าที่ = นักเทคโนโลยีสารสนเทศ และนักคอมพิวเตอร์ ใน Stakeholder Register
- อาจารย์หัวหน้าโครงการ = ผู้อนุมัติการยืมค้างคืนนอกระบบ ไม่ได้ใช้ระบบโดยตรง
- ภาควิชาของตนเอง = ภาควิชาที่ระบบยืนยันตัวตนส่งกลับมาสำหรับผู้ใช้นั้น (IF-IDP-01)
- วันที่ปัจจุบัน / เวลาปัจจุบัน / วันเดียวกัน = เทียบด้วยเขตเวลา Asia/Bangkok
