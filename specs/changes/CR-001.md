# CR-001: ปรับการแสดงกำหนดคืนให้นักศึกษาเมื่ออุปกรณ์เลยกำหนดคืน
Status: **Approved with modification** | ยื่นคำขอ: 2569-10-01 | ตัดสิน: 2569-10-03
ผู้ยื่น: เจ้าหน้าที่ภาควิชา | ผู้ตัดสิน: อาจารย์หัวหน้าโครงการ
กระทบ: SPEC-EQS-001 (UC-01) Draft v2 -> v3

## 1. คำขอ
ทีมยืนยัน Q-01 กับเจ้าหน้าที่ภาควิชาอีกครั้งก่อน freeze spec ตามที่ spec แนะนำไว้ เจ้าหน้าที่จึงขอให้
**ไม่ต้องแสดงกำหนดคืนให้นักศึกษาเห็นเลย** (ตัด FR-EQS-04 ส่วนกำหนดคืนออก)

**เหตุผลของผู้ยื่น**
- ผู้ยืมจำนวนมากคืนช้ากว่ากำหนด หน้าจอจึงโชว์วันที่ที่ผ่านไปแล้ว (เช่น วันนี้ 10 ต.ค. แต่ขึ้นว่าคืน 5 ต.ค.)
- นักศึกษาเห็นวันนั้นแล้วมาถามหรือมาทวงที่เคาน์เตอร์ ซึ่งเป็นภาระที่ระบบนี้ตั้งใจจะลดตั้งแต่แรก (Goal ของ spec)

### 2.2 ประเมินงานและความเสี่ยง
- **Effort**: เล็ก (ประมาณ 0.5-1 วัน) แก้ DTO และ service 1 จุด, เพิ่ม StatusBadge 1 แบบ, เพิ่ม test 2-3 ตัว
- **Schedule**: ไม่กระทบ milestone เพราะอยู่ใน M3 (Detail + role DTO) ซึ่งยังไม่เริ่ม
- **Risk**: ถ้าเลือก "เลยกำหนด" ด้วยเวลาเครื่อง server ที่ timezone ผิด ป้ายจะขึ้นผิดวัน -> ต้องคำนวณตาม Asia/Bangkok
- **Conflict**: ถ้าตัดตามคำขอเดิมทั้งหมด จะขัดกับข้อตกลง N-01 และตัวแทนนักศึกษาจะไม่มีข้อมูลไว้วางแผนแทนการจอง

### 2.3 ทางเลือก
| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| A. อนุมัติตามคำขอ (ไม่แสดงกำหนดคืนเลย) | งานน้อยที่สุด เจ้าหน้าที่ไม่ถูกทวงตามวันที่ | ผิดข้อตกลง N-01 นักศึกษากลับไปต้องเดินมาถามว่าเมื่อไรจะว่าง |
| B. ปฏิเสธ (คงเดิม) | ไม่มีงานเพิ่ม | ปัญหาวันที่ที่ผ่านไปแล้วยังอยู่ และเจ้าหน้าที่ยังโดนถาม |
| **C. ปรับคำขอ**: แสดงกำหนดคืน (ระดับวันที่) เฉพาะเมื่อยังไม่เลยกำหนด ถ้าเลยแล้วแสดงป้าย "เลยกำหนดคืน" แทนวันที่ | ไม่มีวันที่ที่ผ่านไปแล้วให้เข้าใจผิด และยังรักษาข้อตกลง N-01 | งานเพิ่มเล็กน้อย, เพิ่ม AC 1 ข้อ |

## 3. ผลการตัดสิน
- **อนุมัติแบบปรับ (ทางเลือก C)** โดยอาจารย์หัวหน้าโครงการ 2569-10-03 (เจ้าหน้าที่และตัวแทนนักศึกษายอมรับ)
- เหตุผล: C แก้ปัญหาที่เจ้าหน้าที่เจอจริง (วันที่ที่ผ่านไปแล้วทำให้เข้าใจผิด) โดยไม่ผิดข้อตกลง N-01 และงานเพิ่มน้อย
- เงื่อนไขเพิ่ม:
  - "เลยกำหนดคืน" คือวันที่ปัจจุบันตามเวลา Asia/Bangkok มากกว่า `expected_return_date`
  - ป้าย "เลยกำหนดคืน" ไม่ใช่สถานะที่ 7 สถานะยังเป็น "ถูกยืม" ตาม CON-DATA-01
  - เจ้าหน้าที่/อาจารย์ยังเห็นวันที่จริงพร้อมป้ายเลยกำหนด เพื่อใช้ติดตามคืน
